# U2-ejercicio30
# Sistema de Reproducción de Contenidos Digitales

**Objetivo principal:** desarrollar un reproductor universal en Java utilizando clases abstractas, herencia y polimorfismo para gestionar diferentes tipos de contenidos multimedia.

El ejercicio implementa una clase abstracta `ContenidoDigital` y tres clases concretas: `Pelicula`, `EpisodioSerie` y `TransmisionEnVivo`, cada una con su propia lógica de reproducción. Además, utiliza una lista de contenidos digitales para ejecutar las reproducciones de manera modular e incorpora validaciones para comprobar si las transmisiones en vivo se encuentran activas.

**Conceptos aplicados:** clases abstractas, herencia, polimorfismo, encapsulamiento, sobrescritura de métodos, ArrayList y validaciones.
